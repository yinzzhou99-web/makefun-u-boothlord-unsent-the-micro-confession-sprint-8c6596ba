**Unsent: The Micro-Confession Sprint** — a two-part micro-confession: a `To:` line and the message exactly as it was typed, one line, no explanation. This one stayed in drafts for three years.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (standard library only, no network) writes the confession to `/output/entry.txt` and checks it against the gate (1–260 chars total, message line ≤ 200 chars).
